Support

Get help

Report a problem or ask a question by opening an issue on GitHub. Please include your PowerPoint version and platform (Windows, Mac or web); the diagnostics panel (press D in the add-in) shows both.

How to use it

  1. In PowerPoint choose Insert → Add-ins (or My Add-ins) and pick Web Page Viewer.
  2. Type an https:// address and click Show page.
  3. Resize or move the box like any other object.
  4. Press F5. The page stays live and clickable.
  5. To change the address, hover over the box in edit view and click ⚙.

Common questions

The box is blank. Many sites (Google, Microsoft sign-in, banks, most social networks) forbid being shown inside another page. Use a page that allows embedding, such as a Power BI or Grafana embed, a YouTube /embed/ link or Wikipedia.

The clicker does not change slides after I click the page. This is expected for up to about 4 seconds, or until the mouse leaves the page. If you need to type into the page, tick Keep keyboard on the page under ⚙.

A file I received shows an unavailable add-in. Open the file, click Enable Editing if it opens in Protected View, and accept the prompt to load Web Page Viewer.

Where is my address stored? Only inside the presentation file. See the privacy policy.
