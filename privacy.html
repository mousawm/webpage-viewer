Web Page Viewer · Privacy · Terms · Support

Privacy policy

Web Page Viewer is a Microsoft Office add-in that shows a web page inside a PowerPoint slide. It has no server, no account, no analytics and no advertising.

What the add-in stores

The web address you enter, and the "keep keyboard on the page" setting, are saved inside your own presentation file using PowerPoint's document settings. They are not sent to us. Anyone who has the file can see the address, so do not put passwords or access tokens in it.

What we collect

Nothing. The add-in does not collect, receive or sell personal data and sets no cookies of its own.

Third parties

  • Web pages you embed. The page you choose loads directly from its own server in your PowerPoint. That site sees your IP address and may set cookies or collect data under its own privacy policy. The add-in asks the browser not to send a referrer.
  • Microsoft. The add-in loads Office.js from Microsoft's content delivery network, and runs inside Microsoft PowerPoint. Microsoft's privacy statement applies to those.
  • GitHub Pages. The add-in's files are hosted on GitHub Pages, which keeps standard server logs under GitHub's privacy statement.

Children

The add-in is a general productivity tool and is not directed at children.

Changes and contact

If this policy changes, the new version will be posted on this page with a new date. Questions: open an issue on GitHub.
